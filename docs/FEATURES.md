# 益智游戏PK网 (Puzzle PK) - 核心功能与架构清单

本文档汇总系统当前核心技术栈、公共组件设计系统与游戏功能矩阵。

---

## 1. 系统技术架构

### 前端技术栈 (Angular 21 + TailwindCSS v4)
- **Zoneless 响应式**：基于 Angular 21 Signals 驱动，无 `zone.js`，实现毫秒级变更检测与轻量运行。
- **现代化设计系统**：全站基于全局 CSS 变量定制 Light/Dark 双模主题，杜绝硬编码颜色；支持毛玻璃微拟物与流畅动画。
- **国际化与多语言**：深度适配全球 8 种语言（中、英、繁、日、韩、西、法、德），所有文案统一通过 `i18n.service.ts` 动态加载。
- **全端响应式与动态视口校准 (`WindowSizeService`)**：基于 TailwindCSS 响应式前缀适配手机、平板与桌面；内置针对 iOS/PWA 视口冻结与旋转重排自愈校准。

### 后端技术栈 (Go + Fiber v3)
- **高性能 HTTP & WebSocket**：Fiber v3 构建高吞吐服务，长连接接管房间匹配、对战广播与实时状态同步。
- **轻量解耦设计 (准则第5条)**：单机益智模式完全在客户端浏览器内存运行（零服务端负载与数据库开销）；联机 PK 模式强制由服务端计算仲裁与计分。
- **数据持久化**：基于 GORM + PostgreSQL，支撑账户鉴权、段位积分、全球排行榜与系统配置。

## 2. 核心公共组件与设计规范

| 组件 / 架构模块 | 核心功能与设计规范 |
| :--- | :--- |
| **`<app-game-layout>`** | 游戏页统一框架与**智能生命周期编排器（Auto-Orchestrator）**：支持传入 `[store]="store"` 一键自动接管非单人等待室 (`GameWaitingRoom`)、3 秒倒计时覆层 (`GameStartingOverlay`)、终局结算浮层 (`GameResultOverlay`) 与胜负/经验/重开闭环；同时包含顶栏信息、规则弹窗、分享/全屏、以及移动端靠右滑动抽屉导航 (`animate-slide-in-right`)，完美契合右手大拇指触控。 |
| **`BaseGameComponent`** | **全平台极简基类（DX Hub）**：自动托管 `authStore`、`router`、`toast`、`audio`、`haptic`、`leaderboard` 等核心服务；默认推导 `playerId`，内置通用枚举与模板工具；内置桌面全局快捷键（`Esc`/`R`/`Ctrl+Z`/`U`/`H`）；内置零延迟通关多巴胺礼花喷射 (`celebrateVictory()`) 与语义化触感反馈快捷通道 (`vibrate*`)。 |
| **桌面端全局快捷键体系** | `Esc` 极速关弹窗、`R` 键一键重开/再来一局、`Ctrl+Z` / `U` 键智能全局撤销、`H` 键智能锦囊提示；自动防表单输入误触并提供子类重写钩子。 |
| **通关多巴胺微动效 (`celebrateVictory`)** | 消除最后一格或破解谜题第 0ms 瞬间爆发的屏幕双侧礼炮粒子光效与胜利触感，杜绝等待弹窗的割裂感；内置 `prefers-reduced-motion` 保护。 |
| **全平台全游戏触觉震感网络** | 覆盖扫雷、推箱子、五子棋、2048系列、成语接龙、密码破译、数织、俄罗斯方块、水排序等全部 18 款游戏的关键动作、Combo 连击与终局胜负。 |
| **`<app-game-score-capsule>`** | 平台标准化得分信息胶囊：左侧当前分，中间投影槽（主题切换、步数/计时、一键重开），右侧个人最佳（👑）与全网最高纪录（🏆带 Popover）。 |
| **`<app-game-toolbar>`** | 自适应紧凑操作栏，统一各游戏操作按钮（撤销、重开、提示、上一关、下一关、换字）。提示按钮纯净解耦，点击 0ms 即时派发。 |
| **`<app-game-pk-hud>`** | 联机 PK 专属对战面板，实时展示对手进度、步数、生命状态与多回合制 BO3/BO5 局势比分。 |
| **难度本地持久化 (`browser.util.ts`)** | `getSavedDifficulty` / `setSavedDifficulty` 标准工具，全游戏单机难度自动保存与退出记忆，告别重复选难度的割裂感。 |
| **高宽容触觉磁吸 (`HapticService`)** | 拖拽类游戏（方块消除、六边形消除）配备 ~1.65 格大半径容错磁吸与微震感脉冲反馈，搭配主题色白虚线高光虚影 (`.block-ghost-cell`)。 |
