# 益智游戏PK网 (Puzzle PK) - 核心功能与架构清单

本文档汇总系统当前核心技术栈、公共组件设计系统与游戏功能矩阵。

---

## 1. 系统技术架构

### 前端技术栈 (Angular 21 + TailwindCSS v4)
- **Zoneless 响应式**：基于 Angular 21 Signals 驱动，无 `zone.js`，实现毫秒级变更检测与轻量运行。
- **现代化设计系统**：全站基于全局 CSS 变量定制 Light/Dark 双模主题，杜绝硬编码颜色；支持毛玻璃微拟物与流畅动画。
- **国际化与多语言**：深度适配全球 8 种语言（中、英、繁、日、韩、西、法、德），所有文案统一通过 `i18n.service.ts` 动态加载。
- **全端响应式与动态视口校准 (`WindowSizeService`)**：基于 TailwindCSS 响应式前缀适配手机、平板与桌面；内置针对 iOS/PWA 视口冻结与旋转重排自愈校准。

### 后端技术栈 (Go + Fiber v3)
- **高性能 HTTP & WebSocket**：Fiber v3 构建高吞吐服务，长连接接管房间匹配、对战广播与实时状态同步。
- **轻量解耦设计 (准则第5条)**：单机益智模式完全在客户端浏览器内存运行（零服务端负载与数据库开销）；联机 PK 模式强制由服务端计算仲裁与计分。
- **全平台引擎基类化与存量老游戏规范收敛 (`BaseEngine`)**：全量 17 款联机游戏引擎统一继承 `BaseEngine`，支持强类型 `ParseGameOptions` 零崩溃参数提取、统一 3 秒倒计时调度 (`TriggerCountdown`)、标准状态映射 (`StandardStateMap`) 与 `Players map[string]*BasePlayer` 规范导出，彻底消除老游戏分散的冗余断言与重复 goroutine。
- **数据持久化**：基于 GORM + PostgreSQL，支撑账户鉴权、段位积分、全球排行榜与系统配置。
