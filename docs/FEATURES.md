# 益智游戏PK网 (Puzzle PK) - 核心功能清单

本文档汇总系统当前实际实现的最新架构体系与核心功能特性。

---

## 1. 系统技术架构

### 前端技术栈 (Angular 21 + TailwindCSS v4)
- **Zoneless 无区化响应式**：全面基于 Angular 21 Signals 驱动，彻底移除 `zone.js`，实现毫秒级变更检测与轻量运行。
- **现代化设计系统**：全站严格基于 CSS 变量定制 Light/Dark 双模主题，杜绝硬编码颜色；采用毛玻璃微拟物与流光动效。
- **国际化与多语言**：深度适配全球 8 种主流语言（中、英、繁、日、韩、西、法、德），所有文案统一通过 `i18n.service.ts` 动态加载。
- **全端响应式**：基于 TailwindCSS 响应式前缀（`sm:`, `md:`, `lg:` 等）无缝适配手机、平板与桌面宽屏，杜绝横向滚动条。

### 后端技术栈 (Go + Fiber v3)
- **高性能 HTTP & WebSocket**：采用 Fiber v3 构建高吞吐服务，长连接接管房间匹配、对战广播与实时对战。
- **轻量架构设计**：单机模式完全在客户端本地内存运行（零服务端负载）；联机 PK 模式由服务端进行状态同步、仲裁与积分落盘。
- **数据持久化**：基于 GORM + PostgreSQL，支持用户账户、段位积分、战绩排行榜与游戏元数据动态配置。

## 2. 核心架构与公共组件

- **顶栏大一统架构 (`app-game-header` & `main-layout`)**：
  - 消灭独立占行的次级工具栏，三段式布局两侧集成对战动作与实用小工具，为全站 18 款游戏释放 50px 棋盘垂直空间；
  - **全端自适应弹性居中防碰撞机制**：难度胶囊在移动端与平板端（iPad 768px~1080px）采用自适应弹性安全居中 (`mx-auto` + `empty:hidden`)，仅在超宽桌面端启用视口绝对居中 (`xl:absolute`)，杜绝与右侧对战动作按钮相互重叠；
  - **主站导航全设备响应式设计**：全局主导航在 `< 1280px`（涵盖所有 iPad 系列）收纳进侧滑抽屉汉堡菜单，大屏展开横向完整导航栏，确保主题、语言切换与用户状态栏在平板端具备充足呼吸感；
  - **PK 竞技大厅头部高对比度与自适应背景**：消除浅色模式下粉灰浑浊的渐变层，统一采用原生卡片背景与深色渐变切换，在线玩家与房间数采用独立胶囊徽标呈现，彻底杜绝文字泛白与辨识度低的问题。
- **大一统游戏基类 (`BaseGameStore` / `BaseGameComponent`)**：
  - 强制标准化游戏生命周期（Waiting/Starting/Playing/Finished）与玩家列表契约；
  - 统一封装开房、入房、换游戏、重玩、多局胜负制（BO3/BO5）逻辑，消除各子游戏样板代码。
- **全域开房感知与即时应战体系**：
  - **顶栏对战呼吸灯**：全局 WebSocket 监听，有新开房间时实时触发流光与红黄声波微标，可下拉一键迎战；
  - **首页等待卡片流**：首页即时展示等待席位与声波动画；
  - **局内挑战胶囊**：单机游玩时右下角智能滑入轻量化挑战药丸，支持即刻应战或 8 秒自动隐退。
- **结算成就大面板与双重浮空奖励徽标 (`app-game-result-overlay` & `app-xp-gain-badge`)**：
  - 控制台级结算面板，集成荣誉勋章、动态经验条、战绩矩阵（用时/步数/分差）与一键复制带参挑战链接；
  - **通关双重奖励收获浮动动效**：结算时右下角同步弹出「✨ +XP」与「🪙 +脑力币」双胶囊，XP 在 2.3 秒先行淡出，脑力币在 2.6 秒优雅随之淡出，形成极具正反馈的收获节奏；
  - **全站通用结算层收敛**：通过 `GameStatsService.submitStat` 全局拦截统一分发金币与经验奖励，无需每个游戏重复开发。
- **全站统一金色脑力币矢量图标体系 (`CoinIconComponent`)**：
  - 彻底抹平苹果 iOS / iPadOS 与各操作系统对 `🪙` Emoji 渲染为暗淡古铜币的字体差异，确保在全端具备金灿灿的高级质感；
  - 采用多层金色渐变（#FFE57F 至 #B45309）、3D 倒角外圈、微雕点阵与五角星浮雕，并支持 `xs` / `sm` / `md` / `lg` / `xl` 响应式预设与自定义尺寸；
  - 贯穿主站顶栏资产药丸、游戏内头部、规则弹窗、经验与货币双浮空动效、对决大结算面板、商城与任务模块。
- **路由感知与偏好记忆的全屏专注模式 (`ZenModeService`)**：
  - **大厅顶栏智能常驻保全**：基于当前路由与用户偏好计算 (`computed(() => this.isGameRoute() && this.zenPreference())`)，游戏内开启专注模式后返回大厅，全局 Logo、货币余额、排行榜与导航栏 100% 正常显示；
  - **游戏内专注偏好记忆自动恢复**：用户开启专注偏好后持久化存入 `localStorage`，重新进入任意游戏自动激活全屏专注沉浸状态，免去重复操作；
  - **跨设备原生全屏联动**：支持 Esc 键与离开游戏时自动平滑退回原生全屏。
- **大厅移动端压缩与骨架屏 (`LobbyComponent`)**：
  移动端 Hero 标题精简、入口卡片采用双列栅格紧凑排版，首屏直接释放 180px 高度；内置与卡片网格严格对齐的脉冲骨架屏，解决数据水合抖动。
- **渐进式阶梯转化体系 (`AuthModalService` & `AuthModalOverlayComponent`)**：
  - **单机模式 100% 免注册零门槛**：所有单机游戏纯前端内存计算，保护自然 SEO 流量与试玩率；
  - **主动 PK / 排位竞技特权门禁**：大厅进入竞技场与游戏内开房对决拦截未登录访客，唤起全服天梯特权弹窗，支持带 `returnUrl` 原位回跳；
  - **受邀参战游客友好兼顾**：好友房链接直接加入切磋，局内标明「👀 游客试玩模式 (不计排位胜点)」；
  - **对决结算高光转化暴击**：PK 胜后触发金色流光胜点认领卡（+25 LP 入库），战败触发复盘复仇卡，实现高转化闭环；
  - **8 国语言全覆盖**：所有新增文案同步沉淀至 8 种语言资源文件中，零硬编码。
- **局内高频爽感消耗体系 (`CoinService` & `HintButtonComponent`)**：
  - **免广告秒开智能提示**：单机游戏内 `HintButtonComponent` 智能感知脑力币，有币（>=20 币）时点击一键扣除 20 脑力币秒出核心解法，跳过 30 秒激励广告，金币不足时无缝 fallback 到广告；
  - **防手滑即时复活双轨制**：游戏失败结算面板新增「⚡ 消耗 50 脑力币原地复活」与「📺 看广告复活」双轨选项；
  - **通关收益显性化循环**：单机获胜奖励 +10 脑力币、PK 获胜奖励 +25 脑力币，结算大面板与顶栏胶囊实时同步最新金币资产，并伴随金色飘字动效；
  - **通用货币扣减接口与服务**：后端新增 `/api/shop/consume` 原子扣减接口，前端通过 `CoinService` 统一接管全局余额变动。
- **积分悬赏擂台赛体系 (方案 2)**：
  - **自定义悬赏开房与改房**：自建房与房主改房设置面板支持配置「擂台悬赏金额」（友好切磋 0 币 / 50 币 / 100 币 / 200 币），余额不足时智能拦截并提示引导；
  - **大厅流金色悬赏标识**：跨游戏房间列表与卡片流实时渲染金色流光徽章 `🪙 赏金擂台: {{ bounty }} 币`，加入前进行余额门禁校验；
  - **胜者通吃与抗通胀抽水销毁**：胜者赢得双倍押注奖池的 90%（系统抽水 10% 销毁以对抗通胀），负者全额罚没押注，逃跑或掉线由后端裁决罚没；
  - **结算面板高光奖金暴击**：PK 结算面板与顶栏全自动联动，以金色流光奖池条清晰展示独揽奖金净收益与实时余额同步；
  - **全链路架构解耦与状态贯穿**：Go WebSocket 广播层与 REST 结算接口原子打通 `bountyCoins` 仲裁链路，前端 `BaseGameStore` 与 `GameResultOverlayComponent` 高度封装、零侵入适配全站 18 款游戏。
- **管理员登录与路由守卫重定向体系**：
  - 管理员账号登录后若未携带来源地址，系统自动重定向至管理后台实时大厅 (`/:lang/admin/realtime`)，杜绝管理员登录后误跳大厅导致的“登陆未生效”假象；
  - 增强 `adminGuard`，未登录用户访问 `/admin` 时保留原始访问目标，并携带 `returnUrl` 规范重定向至登录页；已登录非管理员用户重定向至大厅；
  - 修复 `authInterceptor` 中 401 报错时缺少语言前缀的旧式硬编码路由问题。
- **配置驱动脑力币经济系统与管理调控中心 (Live Config-driven Economy)**：
  - **后端配置驱动引擎 (`service.GetEconomyConfig`)**：脑力币产出（简单+2/中等+5/困难+10/专家+18/大师+25、PK获胜基础奖励）、道具动作消耗（提示-20、复活-50、连胜冷冻卡-100）、单机每日获取上限（80币）及**新用户注册赠送额度 (`coins.register_bonus`，默认 0 币，靠玩游戏赚取)** 全量收敛至 `system_settings` 数据字典，绝无硬编码，随 `/api/v1/settings` 动态下发；
  - **管理后台可视化调控中心 (`/admin/xp-config`)**：管理后台升级为「数值与代币经济配置」，提供「🪙 脑力币经济系统」与「✨ 经验值等级体系」双标签页，支持对 10 项核心代币产出及消耗参数进行在线调整，一键持久化保存即刻生效，无需重启重构；
  - **前台「脑力币规则与收支指南」手册 (`CoinGuideModalComponent`)**：点击主站顶栏或各游戏顶栏 `🪙 {{ coins }}` 胶囊一键唤起规则指南弹窗，动态展示如何赚取（各难度通关阶梯收益、防刷币每日上限、PK胜局、每日任务）与如何消费（免广告提示、复活、防断签保护卡、商城装扮），数值 100% 绑定后台最新配置；
  - **局内操作动态明码标价**：`HintButtonComponent` 与 `GameResultOverlayComponent` 彻底告别旧式硬编码，根据后台最新配置动态呈现提示按钮文案与复活按钮扣减单价；
  - **8 国语言国际化与全端响应式**：新增 32 条多语言词条（zh/en/ja/ko/es/pt/fr/de），严格遵循全站 CSS 变量与移动端适配规范。
- **SEO 与广告生态**：
  动态 `SeoService` 深度匹配“益智游戏PK网”高权重搜索词；17 篇深度策略博文与 18 款游戏实现双向内链闭环；集成适配 SPA 路由的 Google AdSense 组件。
