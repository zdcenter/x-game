# 扫雷背后的隐藏逻辑

许多休闲玩家将扫雷视为一款靠运气的游戏，盲目点击直到不可避免地踩到地雷。然而，在其简单的外表之下，隐藏着一个纯粹的逻辑和概率游戏。这是一份指南，帮助你揭开扫雷的隐藏逻辑并持续获胜。

## 1. 理解数字
扫雷的核心很简单：方块上的数字告诉你它周围（水平、垂直或对角线）到底有多少个地雷。因此，“1”意味着正好有一个地雷接触该方块，“2”意味着有两个地雷，以此类推。

## 2. 1-1 模式
在平直边缘上最常见和最有用的模式之一是“1-1 模式”。如果你在未揭开方块的直线上有两个相邻的“1”，那么从边缘向外的第三个方块总是安全的。这是因为这两个“1”共享相同的两个可能的地雷位置，这意味着地雷必定在这两个位置之一，从而使相邻的位置变得安全。

## 3. 1-2-1 模式
当你看到一排未揭开方块旁边出现 1-2-1 的序列时，地雷总是直接位于两个“1”的对面。位于“2”对面的方块总是安全的。这种模式非常可靠，并且几乎在每局游戏中都会频繁出现。

## 4. 1-2-2-1 模式
与 1-2-1 类似，1-2-2-1 模式决定了地雷位于两个“2”的对面，而“1”对面的方块是安全的。快速识别这些模式将大幅加快你的游戏速度。

## 5. 何时需要猜测
尽管你付出了最大的逻辑努力，但在扫雷中仍有一些情况你必须猜测。这通常发生在游戏即将结束时，或者当你被迫陷入 50/50 的二选一境地时。在猜测时，尝试做出这样的猜测：如果猜对了，它将为你提供最多的信息来解决棋盘的其余部分。
