## 拼图方块 (Block Puzzle / 1010!) 大师级高阶攻略与空间博弈论

欢迎来到 **拼图方块 (Block Puzzle)** 权威大师研习指南。本游戏建立在 10×10 经典离散几何平面的空间收纳与消除理论之上。与受重力下落和实时计时器压迫的传统下落式方块不同，拼图方块将物理下落约束完全剥离，赋予玩家在 100 格无重力矩阵中进行绝对纯粹的几何规划与组合优化自由。

然而，没有时间限制并不意味着难度降低。方块具有「**离散刚体不可旋转性**」与「**批次发牌强约束性**」，任何一步随性的落子都可能导致棋盘空间熵急剧升高，直至暴毙出局。本指南通过空间拓扑学、概率矩阵分析与高阶消除定式，系统性拆解从万分新手晋升为十万分殿堂大师的全部核心秘密。

### 第一章：几何演化与无重力拼图空间论

#### 1.1 从重力堆叠到无重力自由收纳的范式跃迁
经典《俄罗斯方块》（Tetris）的核心逻辑是受牛顿力学重力场支配的动态下落堆叠：拼块自上方匀速或加速下坠，玩家只能在触底锁定的有限窗口内进行旋转、平移与软降/硬降。

而在 **Block Puzzle (1010!)** 中，重力加速度 g 恒等于 0。
- **全空间自由选择权**：只要目标区域能够完整容纳该几何刚体，你可以将其落子于棋盘 10×10 矩阵内的任意行与列。
- **静态博弈论特征**：没有倒计时催促，玩家拥有近乎无限的单步演算时间。决定胜负的不再是神经反射手速，而是对未来空间拓扑演化的数学预判力。

#### 1.2 空间熵增与棋盘死局的本质
一个全新的 10×10 棋盘共有 100 个空白网格，此时空间熵最低，可容纳的拼块集合覆盖率达到 100%。

随着玩家不断向棋盘填充方块：
1. **连续空间被切割**：原本连续平整的 10×10 空间被分割成若干零散、凹凸不平的不规则残余连通块（Connected Components）。
2. **碎片化惩罚**：当残余连通块的面积虽然总和很大（例如还有 40 个空格），但由于被零散分割成单格（1×1）、孤立死角或狭窄缝隙时，棋盘对大尺寸拼块（如 3×3 正方形、1×5 长条、3×3 大 L）的容纳概率迅速跌落至 0%。
3. **空间塌缩猝死**：一旦下方备选区刷出无法容纳的大型刚体，整局游戏即刻强制中止。因此，高阶博弈的核心本质就是——**最大化抑制空间熵增，维持大尺寸连通空域的动态平衡**。

### 第二章：离散刚体拼块矩阵与无旋转不可逆公理

#### 2.1 不可旋转公理（No-Rotation Invariance）
在下落式俄罗斯方块中，玩家可以通过顺时针或逆时针旋转调整方块姿态；而在 Block Puzzle 经典规则中，**所有拼块的方向是绝对锁死的，完全无法旋转**。

这意味着：
- 一个朝上的 L 型与一个朝左的 L 型在逻辑上属于两个完全不同的几何元素，不能相互替代。
- 玩家无法期待通过旋转来“拯救”不契合的地形，唯一的救赎是通过提前规划消除来改造棋盘。

### 第三章：空间熵与九宫格保留定理（Survival Theorem）

#### 3.1 3×3 九宫格避难所绝对定理
在统计学模型中，当游戏步数超过 100 步时，3×3 超巨型正方形的单轮抽中期望值高达 12.8%。
如果你的棋盘上没有任何一块 3×3 的连续空白矩阵：
- 当抽签池触发 3×3 正方形时，你的**即时暴毙概率为 100%**。
- 高手与新手的本质分野就在于：新手在棋盘塞满 80% 时疲于应付眼前单行，而大师在下棋的每一手都在心中用探照灯扫描棋盘上是否存在至少一个「**3×3 圣地**」。

#### 3.2 边角保留与中腹留白法则
- **边角吸附法则**：所有带有凸起或直角的形状，优先从棋盘的四个角落或边缘贴边向内推进。将边缘作为天然边界，能最大限度减少向外暴露的不规则表面积。
- **中腹通透法则**：避免在 10×10 棋盘的第 4~7 行与第 4~7 列（中央区域）散落零碎单格。中腹是横向与纵向长条拼块通行的“生命大动脉”，中腹一旦堵死，棋盘将被瞬间切割成孤立的四个小块。

### 第四章：人类大师高阶推演定式

#### 定式一：三手统筹（Triad Batch Evaluation）
Block Puzzle 的发牌机制不是每下一步补一个，而是**以 3 块为一组整批派发**。只有当手牌中的 3 个拼块全部成功落子于棋盘后，系统才会重新生成下一批 3 个拼块。

大师执棋的第一铁律：
> **「绝不在未推演完手牌全部三张拼块之前，盲目放下第一块！」**

必须在脑海中完成三步置换推演：
- 规划顺序：`A → B → C`，还是 `B → A → C`？
- **清线腾挪效应**：落子 A 是否能够瞬间触发某一行消除，从而为原本无法摆放的巨大拼块 B 创造出全新空间？这是化解必死手牌的唯一神技！

#### 定式二：十字交叉爆发双清（Cross-Clear Trap）
单行消除（100 分）不仅收益极低，还会浪费拼块的接触面积。大师会故意在某一个交汇单元格保留空白，同时将该行与该列的其余 9 格全部填满：

```
十字双清触发前夕 (C 点为空白)：
       Col 4
Row 3: # # # [C] # # # # # #  ← 水平仅差 C 格填满
              #
              #
              #
              #
              #
              ↑ 垂直仅差 C 格填满

此时只需投入一个简单的 1×1 或任意覆盖 C 点的拼块，
瞬间同时引爆 Row 3 与 Col 4，触发双倍多线暴击加成！
```

#### 定式三：边缘阶梯筑壁（Stepped Perimeter Wall）
利用 L 型与长条拼块紧贴棋盘四壁堆叠，使未填满的缺口呈现平滑的阶梯状（如 3-2-1 递减），而不是充满锯齿状的尖刺深谷。阶梯状地形能够兼容绝大多数 1×2、2×2、L 型及长条，几乎不会产生死穴。

#### 定式四：连击链维持律（Combo Cascade Flow）
每次落子若能连续触发至少 1 行/列消除，连击计数器（Combo Multiplier）将不断递增：
- 连续 2 步消除：得分 ×1.5
- 连续 3 步消除：得分 ×2.0
- 连续 4 步消除：得分 ×2.5
- 连续 5 步及以上：得分 ×3.0 及以上！
保持连击链是冲击排行榜数十万分的唯一捷径。当面对多个可行落子点时，优先选择能「在本步消除」或「为下一步确保持续消除」的点位。

#### 定式五：断臂止血弃线法（Emergency Line Sacrifice）
当棋盘形势恶化、空间极度拥挤且手牌即将面临 3×3 或长条卡死时，果断放弃憋多线大招的幻想，哪怕只能消除 1 条线，也立刻用手头最别扭的拼块触发消除，以最小代价换取棋盘生存韧性。

### 第五章：超线性得分函数与积分最大化算法模型

Block Puzzle 拥有严谨精妙的数学积分模型，玩家的单局终局得分由四大分量累加而成：

#### 5.1 基础落子分（Block Placement Points）
每成功摆放一个拼块，获得等同于该拼块物理格子数量的基础积分：
`S_place = N_cells`（例如 3×3 正方形入场即得 9 分，1×5 长条得 5 分）。

#### 5.2 多线同消指数暴击（Multi-Line Clear Multiplier）
在同一步骤中消除的行数与列数总和记为 `L`，消除得分呈现剧烈的超线性增长：

| 一步消除线数 (L) | 基础消除分 (S_lines) | 得分倍率比值 | 战术评定 |
| :---: | :---: | :---: | :--- |
| **1 线** (单行/单列) | **100 分** | 1.0× | 基础保命，常规操作 |
| **2 线** (双行/双列/十字) | **360 分** | 3.6× | 核心得分手段，性价比极高 |
| **3 线** (三线同消) | **800 分** | 8.0× | 高阶战术爆发，分数质的飞跃 |
| **4 线** (大四喜同消) | **1,600 分** | 16.0× | 完美布局，全屏激光轰鸣 |
| **5 线及以上** (神级清屏) | **3,000 分+** | 30.0×+ | 史诗级几何奇迹，直接锁定榜首 |

#### 5.3 连击倍率公式（Combo Dynamic Scaling）
连续消除步数记为 `C`（当某一步未产生任何消除时，C 重置为 0）：
`Combo_Multiplier = 1 + 0.5 × (C - 1)` (当 C ≥ 1)
总得分计算：`Total_Step_Score = S_place + S_lines × Combo_Multiplier`。
> 例如：在 4 连击状态下完成一次 3 线同消，单步斩获积分高达：
> `S = 5 + 800 × (1 + 0.5 × 3) = 5 + 800 × 2.5 = 2,005 分`！

#### 5.4 完美全清彩蛋奖励（All-Clear Board Wipe）
如果某一步消除后，整个 10×10 棋盘的 100 个格子全部变为空白（无任何残余积木）：
系统将额外触发 **PERFECT ALL-CLEAR** 极彩爆裂特效，并一次性嘉奖 **1,500 点巨额净分**！

- 双方玩家接收到的手牌拼块序列及其先后出现顺序是**绝对一致**的。

### 第七章：高频常见疑难解答 (FAQ) 与十二字心诀

#### Q1: 到底能不能旋转方块？按哪个键可以旋转？
**答**：绝对不能旋转。这是 Block Puzzle 最核心的几何公理。请改变适应地形的思维，通过利用当前形状来主动塑造下一次消除后的新地形。

#### Q2: 为什么游戏经常刷出根本放不下的拼块？是系统在故意针对我吗？
**答**：完全不是。系统生成拼块是基于均匀权重或固定概率池的。之所以感到“被针对”，是因为你的棋盘空间熵已经过高——出现了大量单格洼地和破碎断层。只要严格执行「恒留 3×3 安全区」法则，系统发出的绝大多数拼块都能够从容安放。

#### Q3: 键盘和鼠标/触屏哪种操作更适合冲分？
**答**：
- **触屏/鼠标拖拽**：最直观流畅，沉浸感极强；我们内置了触控垂直偏移防遮挡算法，手指下方绝不会遮挡视线。
- **数字键 + 键盘光标**：专为硬核电竞玩家设计。按 <kbd>1</kbd>/<kbd>2</kbd>/<kbd>3</kbd> 秒选拼块，<kbd>WASD</kbd> 极速定位，<kbd>Space</kbd> 瞬间落子，兼顾精准度与极致反应。
